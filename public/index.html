go.oicana.com

Generate PDFs in Go from Typst templates, without a headless browser.

Add the module and fetch the native library for your platform:

go get go.oicana.com/oicana
export CGO_LDFLAGS="$(go run go.oicana.com/oicana/cmd/oicana-install)"
go build ./...

The module links its native library through cgo, so it needs a C toolchain (MinGW-w64 on Windows). In PowerShell, use $env:CGO_LDFLAGS = go run go.oicana.com/oicana/cmd/oicana-install.
